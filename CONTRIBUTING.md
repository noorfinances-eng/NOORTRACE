# Contributing

Thank you for considering a contribution.

- Open an issue before a large change, so the design can be discussed first.
- Every rule of the specification is testable; a change to a format comes with its
  test vectors and with both implementations updated (JavaScript reference and Go
  verifier), which must agree byte for byte.
- Code and comments in English in this repository. Keep the existing style of the
  file you touch.
- Run the test suite before opening a pull request: `npm install && npm test`.
- By contributing, you agree that your contribution is licensed under the Apache
  License 2.0 of this repository.
